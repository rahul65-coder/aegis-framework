## Core Principle

Evidence > Claims.

The system must never treat verbal completion as actual completion.

PHASE 0 -> PHASE 1 -> PHASE 2 -> PHASE 3 -> PHASE 4 -> PHASE 5 -> PHASE 6 -> PHASE 7 -> PHASE 8 -> PHASE 9 -> PHASE 10 -> PHASE 11 -> PHASE 12 -> PHASE 13

## Phase 0 Foundation

## Future Phases

Phase 1 and later must be implemented only after Phase 0 is STABLE.

## Non-Negotiable Rules

1. Do not redesign the approved architecture.
2. Do not silently remove features.
3. Do not simplify required modules.
4. Do not replace approved technologies without approval.
5. Do not invent requirements.
6. Do not skip phases.
7. Do not declare a phase stable without objective evidence.
8. Do not move to the next phase while the current phase is unstable.
9. Previous phases must not regress.
10. Git history and verification evidence are mandatory.
